# Aplicação DoeBem

Esta pasta será utilizada para organizar o código-fonte da aplicação web DoeBem, desenvolvida com Python e Django.

## Funcionalidades previstas
- Gerenciamento de campanhas.
- Registro de doações.
- Controle de agasalhos disponíveis.
- Registro de entregas.
- Consulta ao histórico de movimentações.

## Situação
Estrutura inicial reservada para a implementação do MVP.
