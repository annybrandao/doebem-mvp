# Requisitos do Sistema DoeBem

## Objetivo
Desenvolver uma aplicação web para auxiliar a Associação de Moradores do Condomínio Ville Blanche na organização de campanhas de arrecadação e distribuição de agasalhos.

## Requisitos funcionais

- RF01: Permitir o cadastro de campanhas.
- RF02: Permitir o registro de doações, informando campanha, tipo de agasalho, quantidade e data.
- RF03: Apresentar a quantidade disponível de cada tipo de agasalho por campanha.
- RF04: Permitir o registro de entregas, impedindo quantidades superiores ao saldo disponível.
- RF05: Permitir a consulta ao histórico de movimentações por campanha.

## Requisitos não funcionais

- RNF01: Exigir autenticação para acessar as operações do sistema.
- RNF02: Validar os dados e proteger as informações.
- RNF03: Permitir acesso por navegador em dispositivos móveis e computadores.
- RNF04: Apresentar interface responsiva e acessível.

## Prioridades
Os requisitos RF01, RF02, RF03 e RF04 são essenciais para o MVP. O RF05 é desejável e poderá ser desenvolvido após as funcionalidades principais.
