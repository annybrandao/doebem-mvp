# DoeBem – Sistema de Gestão de Doações Comunitárias

## Sobre o projeto
O DoeBem é um MVP de aplicação web desenvolvido para auxiliar a Associação de Moradores do Condomínio Ville Blanche, em Valparaíso de Goiás, na organização de campanhas de arrecadação e distribuição de agasalhos.

## Objetivo
Centralizar o registro de campanhas, doações e entregas, facilitando o acompanhamento das quantidades disponíveis e do histórico das movimentações.

## Funcionalidades previstas
- Cadastro de campanhas;
- Registro de doações;
- Controle de agasalhos disponíveis;
- Registro de entregas;
- Consulta ao histórico de movimentações.

## Tecnologias
- Python 3.14
- Django 5.2
- HTML5 e CSS3
- Bootstrap 5.3
- SQLite

## Situação do projeto
MVP em desenvolvimento acadêmico, com implementação incremental e documentação das etapas realizadas.
